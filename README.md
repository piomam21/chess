# ChessHub frontend

React + TypeScript + Vite + chess.js.

## Start

```bash
npm install
npm run dev
```

## Struktura

- `src/pages/` — widoki aplikacji
- `src/components/chess/` — szachownica, figury SVG, panel partii
- `src/components/layout/` — layout/nawigacja
- `src/components/ui/` — współdzielone elementy UI
- `src/hooks/` — logika React (partia, czat)
- `src/services/` — adaptery REST i realtime do backendu
- `src/types/` — typy domenowe
- `src/data/` — dane mockowe
